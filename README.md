# hassane-azzi.com

Personal portfolio for Hassane AZZI — Operations Research, Optimization, Machine Learning and Software Engineering.

## Stack
- Next.js 15
- React 19
- TypeScript
- CSS
- lucide-react

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Deployment

The project is ready for Vercel, Netlify or any Node.js hosting provider.

### Domain

Point `www.hassane-azzi.com` and `hassane-azzi.com` to the deployment provider and configure the custom domain there.

## Important customization

- Replace the GitHub avatar URL in `app/page.tsx` with a professional portrait when desired.
- Add a PDF resume under `public/` and change the CV link to `/CV-Hassane-AZZI.pdf`.
- Add project images under `public/projects/` when available.
- Update social URLs if your profiles change.
